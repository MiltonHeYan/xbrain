# Agent mark sources

These graphical marks identify tools discussed in the README. They contain no
visible product names or documentation wordmarks. Retrieved 2026-10-03 from
[CoreSpeed's maintained agent-mark collection](https://github.com/corespeed-io/static.corespeed.io/tree/master/public/agents),
using the repository files rather than potentially stale CDN responses. The
collection attributes the Claude Code, OpenAI, and Cursor vectors to Simple
Icons (CC0), and OpenClaw to its official-site favicon. Trademark rights remain
separate from the icon files' copyright license.

| Files | Source and identity |
| --- | --- |
| `claude-code.svg` | [Claude Code pixel mascot](https://github.com/corespeed-io/static.corespeed.io/blob/master/public/agents/claude-code.svg), added in [static #13](https://github.com/corespeed-io/static.corespeed.io/pull/13). Based on the Simple Icons `claudecode` mark. This is distinct from the Claude app mark and the Claude Code Docs wordmark. |
| `openai.svg`, `openai-dark.svg` | CoreSpeed's [OpenAI mark](https://github.com/corespeed-io/static.corespeed.io/blob/master/public/agents/openai.svg), used for Codex in the collection, with its supplied dark-background variant. [OpenAI brand guidelines](https://openai.com/brand/) apply. |
| `cursor.svg`, `cursor-dark.svg` | CoreSpeed's [Cursor mark](https://github.com/corespeed-io/static.corespeed.io/blob/master/public/agents/cursor.svg), with its supplied dark-background variant. [Cursor brand guidelines](https://cursor.com/brand) apply. |
| `openclaw.svg` | CoreSpeed's [OpenClaw mascot](https://github.com/corespeed-io/static.corespeed.io/blob/master/public/agents/openclaw.svg). |

The SVGs are copied without modifying their shapes or colors. Light/dark variants
are selected with `picture` elements. All six SVGs were parsed and rendered for
visual review; the four marks were checked individually.
