    Bring your own agent.

    Your agent handles X access and enrichment. Commonplace stores and displays the results.

    1. Connect X through CoreSpeed

      In your own agent, connect CoreSpeed and authorize the X account you want to read.

    2. Fetch, summarize, and tag

      Ask your agent to fetch the available bookmarks, add short faithful summaries and 1–4 useful tags, then export JSON. Connector coverage may be partial.

    3. Import and keep browsing

      Drop the JSON here, or run the local CLI. Your gallery works without an agent running.

    node cli.mjs import ./bookmarks.json
    npm start

    Full setup, schema, and agent skill are included in the source package. This preview saves imports in this browser. It never connects to X by itself.
